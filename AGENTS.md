# Required GitHub pushes

For every future change to this app, including source, configuration, or project documentation:

1. Complete the authorized work and run checks appropriate to the change.
2. Commit and push the finished changes to `https://github.com/Evans-Brian/coding-practice-tracker` using the `github` remote and the task's target branch (normally `main`).
3. Verify that the remote branch contains the final commit before reporting the task complete.

This is a standing user instruction. Do not ask again for permission to push routine authorized app changes. If a push fails or is blocked, explain the failure and what remains unpushed.

Never commit credentials, private LeetCode history exports, or personal tracker data. Keep the existing Sites publication workflow for changes to the hosted app; a GitHub push is also required.
